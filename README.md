# aulaCompVibeCoding

Repositório de apoio às atividades de **vibe coding** para estudantes dos cursos de Engenharia da Universidade Tecnológica Federal do Paraná (UTFPR), Campus Ponta Grossa (PG).

## Sobre as atividades

Vibe coding é uma forma de desenvolver software usando linguagem natural para orientar ferramentas de inteligência artificial. Nas atividades, os alunos poderão transformar ideias em aplicações, testar soluções e aprender sobre o processo de desenvolvimento. A IA é uma assistente: é importante revisar, compreender e validar o código gerado.

## Ferramentas

- [Lovable](https://lovable.dev/) — cria aplicações web a partir de instruções em linguagem natural e permite iterar sobre interfaces e funcionalidades.
- [Supabase](https://supabase.com/) — oferece serviços de backend, como banco de dados, autenticação e armazenamento, para conectar às aplicações.
- [GitHub](https://github.com/) — hospeda repositórios e apoia o controle de versões e a colaboração nos projetos.
- [Google AI Studio](https://aistudio.google.com/) — permite experimentar modelos Gemini e criar protótipos com inteligência artificial generativa.

## Fluxo sugerido

1. Explore uma ideia e descreva o que a aplicação deve fazer.
2. Use o Lovable para gerar e aprimorar a aplicação.
3. Conecte o Supabase quando o projeto precisar de dados ou autenticação.
4. Use o GitHub para registrar e compartilhar o código.
5. Experimente o Google AI Studio para prototipar funcionalidades com IA.
